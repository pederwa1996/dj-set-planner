DJ Set Planner is a personal tool for planning DJ sets: building a library, checking which tracks mix well together and putting them in a good order.

BPM and key data provided by GetSongBPM.com.

Data sources

  • GetSongBPM — tempo (BPM) and musical key of tracks, through the GetSongBPM API.
  • Deezer — track length, release year, label and 30-second previews.
  • MusicBrainz — track length and first release year.
